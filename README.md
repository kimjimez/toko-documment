# toko-document

คู่มือการใช้งานระบบ TOKO SHOP — Merchant Management Manual

## Build

```bash
./build.sh         # สร้างทั้ง PDF + DOCX
./build.sh pdf     # PDF อย่างเดียว
./build.sh docx    # Word อย่างเดียว
```

## Files

- `TOKO_Shop_Manual.md` — source หลัก
- `header.tex` — LaTeX preamble
- `build.sh` — สคริปต์ build
- `images/` — รูปประกอบ
